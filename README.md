# Overview

I created HomeOrganizer, an Android application that helps users organize different areas of their home. The app includes screens for rooms, tasks, maintenance, and expenses. Users can add rooms, create tasks, and mark tasks as completed. I also connected parts of the app to Firebase to store and retrieve information.

My purpose for developing this software was to improve my understanding of Kotlin and learn how to use it to build an Android application. I wanted to practice working with variables, functions, classes, lists, loops, and conditional statements. I also learned how to use data classes to organize information and how to navigate between different screens. Working on this app helped me understand Kotlin syntax and gave me more experience troubleshooting errors.

# Development Environment

I used Android Studio to develop and test my application. I also used the Android Emulator to run the app and GitHub to save and manage my code.

The main programming language I used was Kotlin. I used Jetpack Compose and Material 3 to create the screens, buttons, cards, and text fields. I also used Firebase Firestore to store and retrieve task information.
